# Kusuri 使用说明（1.3.0）

Kusuri 是一款 Mac 上的 Kindle 图书管理工具。Mac 和 Kindle 连上同一个 Wi-Fi，就能在 Mac 上给 Kindle 传书、改名、删书、整理文件夹，不用再插数据线。

适用于已越狱、并开启了 SSH 服务的 Kindle。

## 一、开始之前

只需准备一次。

### 1. Kindle 已开启 SSH

SSH 是 Kusuri 用来无线连接 Kindle 的方式。越狱后的 Kindle 一般通过 KOReader 或 USBNetwork 插件开启，具体做法请按你越狱时用的教程操作。记下它使用的端口，通常是 `2222`。

### 2. 准备一对「钥匙」

Kusuri 登录 Kindle 时不用密码，而是用一对密钥：私钥留在 Mac 上，公钥放到 Kindle 上。

- **还没有密钥**：打开 Mac 的「终端」，输入下面这行后一路按回车：

  ```bash
  ssh-keygen -t ed25519
  ```

  会生成两个文件：`~/.ssh/id_ed25519`（私钥）和 `~/.ssh/id_ed25519.pub`（公钥）。如果提示文件已存在，说明以前生成过，输入 `n` 退出，直接使用现有的，不要覆盖。

- **把公钥放到 Kindle**：把 `id_ed25519.pub` 里的那一行文字，加到 Kindle 上 SSH 插件指定的 `authorized_keys` 文件中（位置因插件而异，请参考插件说明）。

连接页的「操作帮助」里也有这些步骤。

### 3. 连接时

Mac 和 Kindle 连同一个 Wi-Fi，并让 Kindle 保持唤醒。Kindle 休眠后 Wi-Fi 会断开，Kusuri 也就连不上了。

## 二、安装

1. 双击 Kusuri 的 `.dmg` 安装包。
2. 把 Kusuri 拖进旁边的「应用程序」文件夹。
3. 在「应用程序」里双击 Kusuri 打开。安装包已通过 Apple 公证，第一次打开时 macOS 会问是否打开从网上下载的应用，点「打开」即可。
4. 如果系统询问是否允许 Kusuri 访问本地网络，请选择「允许」，否则找不到 Kindle。

## 三、第一次连接

打开 Kusuri 后，右边是连接表单：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| Kindle IP | 无（必填） | Kindle 在 Wi-Fi 里的地址，例如 `192.168.1.120`。可在 Kindle 的网络信息页面或路由器的「已连接设备」里查到 |
| SSH 端口 | `2222` | 与 Kindle 上的设置一致即可 |
| 用户名 | `root` | 一般不用改 |
| 访问范围 | `/mnt/us/documents` | 即用数据线连电脑时看到的 `documents` 文件夹。想管理整个 Kindle 存储，可改为 `/mnt/us`。Kusuri 只能访问这个范围以内的文件，碰不到 Kindle 的系统区域 |
| SSH 私钥 | `~/.ssh/id_ed25519` | 要换一把，点私钥框选择文件；注意选不带 `.pub` 的那个 |

网络接口、Wi-Fi 名称、网关、MAC 这些栏目只用于对照网络信息，不填也能连接。

**省事的办法**：把 Kindle 网络信息的文字复制下来，点「粘贴识别」，能认出来的栏目会自动填好，例如：

```text
接口：wlan0
SSID：你的 Wi-Fi 名称
IP：192.168.1.120
默认网关：192.168.1.1
SSH 端口：2222
用户名：root
```

填好后点「连接 Kindle」。连接信息只保存在这台 Mac 上；连上过一次，下次打开 Kusuri 会自动重新连接。空闲 30 分钟会自动断开，点刷新或进行任何操作时会自动重连。

## 四、日常使用

### 浏览

- 双击文件夹进入，点上方路径可以返回上一层。
- 点表头可按名称、分类、进度、大小、修改时间、添加时间排序，再点一次反向。
- 顶部显示 Kindle 里的图书总数和已用空间。

### 传书

- 点「上传文件」，或直接把文件、整个文件夹拖进窗口。拖文件夹时，里面的层级会原样保留。
- 支持的格式：epub、azw3、mobi、pdf、txt、cbz、cbr、doc、docx，以及 jpg、png、gif 图片。
- 单个文件最大 2 GB，超过的会被跳过并提示。
- 上传时窗口顶部会显示进度、速度和大约还要多久。点「取消」可随时停下：正在传的那个文件不会留在 Kindle 上，已传完的保留。
- 大文件请让 Kindle 保持唤醒、Wi-Fi 稳定。

### 查看和导出

- 双击文件可直接预览：txt、pdf 和图片能在 Kusuri 里打开，其他格式会提示下载到 Mac 上查看。
- 右键文件选「导出到本地」，可将其存到 Mac。

### 改名

- 右键选「重命名」。只需改书名，后缀（如 `.epub`）会自动保留。
- 如果这本书有 Kindle 或 KOReader 生成的阅读进度、批注文件，Kusuri 会问你是否一起改名。一起改，阅读进度才不会丢。

### 删除和找回

- 右键选「删除」。如果这本书有阅读进度、批注文件，可以选「仅删除图书」，或连同这些文件一起删。
- 删除不会立刻消失：Kusuri 会先把文件备份到这台 Mac 上，保留 30 天。删除时顶部显示「正在删除」和进度；前半段还没动 Kindle，此时可以点「取消」。
- **找回**：点右上角「更多 → 最近删除」，在要找回的那一行点「…」，选「恢复」，文件会放回原来的位置（如果原位置已有同名文件，不会覆盖）。选「彻底删除」则清掉备份，之后就找不回了。

### 新建文件夹、刷新

- 点「新建文件夹」在当前位置建一个文件夹。
- 点刷新按钮重新读取 Kindle 上的内容。

### 最近加入、久未阅读

- 「更多 → 最近加入」：列出最近 7 天放进 Kindle 的书。
- 「更多 → 久未阅读」：列出超过 90 天没翻开过的书。只有能读到上次阅读时间的书才会列出。
- 每本书下面写着它所在的文件夹，例如「言情 · 昨天加入」「根目录 · 120 天未阅读」。点行尾的「…」，可以预览、进入所在文件夹、改名、导出或删除。

### 显示哪些文件

Kindle 里除了书，还有字体、词典、图片，以及 Kindle 自己生成的系统文件。

- 点「更多 → 文件显示」，勾选想看到的类别，可以多选。默认只显示「图书」和「其他」（普通文件夹、空文件夹等）。
- **什么是系统文件**：Kindle 和 KOReader 为每本书自动生成的记录，比如阅读位置、批注（常见的是以 `.sdr` 结尾的文件夹）。删了它们，对应那本书的进度和批注就没了，所以默认隐藏，操作时 Kusuri 也会特别提醒。
- 如果某个文件分错了类（比如词典被当成了图书），右键选「标为系统文件」；想撤回，在「文件显示」里勾上「系统」，再右键选「恢复自动识别」。这个设置只保存在这台 Mac 上。

### 提示

操作结果会在窗口顶部弹出一条提示，几秒后自动消失；出错的提示会多停留一会儿。

## 五、阅读进度

书架的「进度」一栏显示每本书读到了哪里，数据来自 KOReader 或 Kindle 自带的阅读器；两边都有记录时，以 KOReader 的为准。读不到记录的书，这一栏留空。

Kusuri 只读取进度，不会改动 Kindle 或 KOReader 的阅读记录。

## 常见问题

### 连不上 Kindle

1. 唤醒 Kindle，停在正常界面几秒钟。
2. 确认 Mac 和 Kindle 连的是同一个 Wi-Fi。
3. Kindle 的 IP 可能变了，重新查一下。
4. 确认 Kindle 上的 SSH 服务已开启，端口和 Kusuri 里填的一致。
5. 打开 Mac 的「系统设置 → 隐私与安全性 → 本地网络」，确认 Kusuri 的开关已打开。
6. 再点一次「连接 Kindle」。

### 提示「SSH 认证失败」

检查用户名是否正确、所选私钥是否与放到 Kindle 上的公钥配对。

### 提示「本地服务连不上，请稍后重试」

这是 Kusuri 自身的问题，和 Kindle 无关。稍等再试；一直出现的话，退出并重新打开 Kusuri。

### 上传或删除很慢

速度取决于 Wi-Fi，大文件需要一些时间，顶部会显示预计还要多久。期间请让 Kindle 保持唤醒。

### 刚传的书在 Kindle 书库里没出现

Kindle 需要一点时间整理新书，稍等片刻；还是没有的话，重启一下 Kindle。

## 隐私

Kusuri 不需要注册账号，也不经过任何云端服务器。文件只在你的 Mac 和 Kindle 之间直接传输。连接信息只保存在这台 Mac 上，私钥只用来连接 Kindle。

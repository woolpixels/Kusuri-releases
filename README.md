# Kusuri · 薬

管理 Kindle，  
不必再和文件较劲。

连接同一 Wi-Fi 后生效。适用于懒得插线、文件堆积、分类随缘，
以及临时起意整理 Kindle 的 P 人。

## 下载

前往 [Releases](../../releases/latest) 下载最新版。

## 主要功能

- 无线连接 Kindle
- 传输图书与文件
- 重命名、删除与整理文件夹
- 图书 / 字体 / 词典 / 图片 / 其他 / 系统分类
- 最近加入
- 久未阅读
- 最近删除
- 文件预览与导出
- 系统文件标记，减少误删风险

## 使用条件

- Mac 与 Kindle 连接至同一 Wi-Fi
- Kindle 已配置可用的 SFTP / SSH 环境
- 连接成功后即可在 Kusuri 中管理设备文件

## 安全与隐私

Kusuri 在本地连接和管理你的 Kindle。

- 不上传 Kindle 文件
- 不上传图书内容
- 不修改未操作的文件
- 删除等高风险操作会进行确认
